# ProiectTW

DailyHub - Aplicație web pentru organizarea activităților cotidiene

DESCRIEREA PROIECTULUI

DailyHub este o aplicație web destinată organizării activităților personale și colaborative într-un singur loc.

Aplicația permite utilizatorilor să își gestioneze sarcinile, evenimentele și rezervările personale, dar și să colaboreze cu alte persoane prin intermediul unor spații de lucru comune, numite Workspace-uri.

PROBLEMA IDENTIFICATĂ

Organizarea activităților cotidiene presupune adesea utilizarea mai multor aplicații pentru sarcini, calendar, notițe și liste.

Această fragmentare îngreunează urmărirea activităților și colaborarea dintre utilizatori.

DailyHub urmărește centralizarea acestor funcționalități într-o singură aplicație.

OBIECTIVELE PROIECTULUI

- Centralizarea activităților personale într-o interfață accesibilă.
- Organizarea sarcinilor și evenimentelor într-un mod structurat.
- Facilitarea colaborării prin Workspace-uri.
- Permiterea partajării sarcinilor, notițelor și listelor.
- Separarea informațiilor personale de cele colaborative.

UTILIZATORII VIZAȚI

Aplicația se adresează studenților, persoanelor care doresc să își organizeze activitățile zilnice și grupurilor mici care au nevoie de instrumente de colaborare.

FUNCȚIONALITĂȚILE PRINCIPALE

- Înregistrare și autentificare.
- Dashboard pentru activitățile personale.
- Crearea, modificarea și ștergerea sarcinilor personale.
- Gestionarea evenimentelor și rezervărilor personale.
- Crearea și administrarea Workspace-urilor.
- Invitarea utilizatorilor înregistrați în Workspace-uri.
- Acceptarea și refuzarea invitațiilor.
- Gestionarea sarcinilor colaborative.
- Crearea și editarea notițelor comune.
- Gestionarea listelor colaborative.

TEHNOLOGII UTILIZATE

Frontend: HTML5, CSS3, JavaScript.
Backend: Node.js, Express.js.
Baza de date: PostgreSQL.
Versionare și colaborare: Git și GitHub.
