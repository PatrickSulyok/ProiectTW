
DailyHub - Wireframe-uri și navigare

DESCRIERE GENERALĂ

Acest folder conține schițele interfeței aplicației DailyHub. Wireframe-urile prezintă structura principalelor pagini, elementele de interacțiune și modul de navigare între secțiuni.

Schițele sunt orientative și pot fi ajustate în timpul implementării.

ECRANELE APLICAȚIEI

1) Login - 01-login.png

Pagina de autentificare permite utilizatorului să introducă adresa de email și parola pentru a accesa aplicația. Include un link către pagina de înregistrare.

2) Înregistrare - 02-inregistrare.png

Pagina permite crearea unui cont prin introducerea numelui, adresei de email și parolei, cu confirmarea acesteia. Include navigare către autentificare.

3) Dashboard - 03-dashboard.png

Pagina principală afișează un rezumat al sarcinilor personale, evenimentelor apropiate, Workspace-urilor și invitațiilor. Include meniul principal de navigare.

4) My Space - 04-my-space.png

Pagina pentru gestionarea sarcinilor personale. Utilizatorul poate vizualiza, adăuga, modifica, finaliza sau șterge sarcini și poate consulta prioritățile și termenele-limită.

5) Workspaces - 05-workspaces.png

Pagina afișează spațiile de lucru din care utilizatorul face parte și oferă posibilitatea creării unui Workspace nou.

6) Workspace - 06-workspace-interior.png

Pagina internă a unui Workspace permite accesarea sarcinilor, notițelor și listelor colaborative. Include gestionarea membrilor și secțiuni rezervate extinderilor viitoare.

7) Calendar - 07-calendar.png

Pagina prezintă evenimentele personale într-o interfață de tip calendar și permite adăugarea și gestionarea acestora.

8) Invitații - 08-invitatii.png

Pagina permite consultarea invitațiilor primite și trimise. Utilizatorul poate accepta sau refuza invitațiile primite.

9) Flux de navigare - 09-flux-navigare.png

Diagrama prezintă traseele principale dintre autentificare, Dashboard, My Space, Workspaces, Calendar și Invitații.

FLUXUL PRINCIPAL DE NAVIGARE

Utilizatorul neautentificat accesează pagina Login sau Înregistrare.

După autentificare, utilizatorul ajunge în Dashboard.

Din Dashboard, utilizatorul poate accesa My Space, Workspaces, Calendar și Invitații.

Din Workspaces, utilizatorul poate deschide un Workspace și poate naviga între sarcinile, notițele și listele comune.

Meniul lateral permite trecerea între secțiunile principale ale aplicației.

OBSERVAȚII

Wireframe-urile prezintă structura propusă, nu implementarea finală.

Modulele Buget și Documente sunt planificate pentru etape ulterioare și nu sunt obligatorii pentru prima versiune MVP.

Modificările notițelor comune vor deveni vizibile după salvare și reîncărcare, fără sincronizare în timp real.

Designul final poate include alte culori, pictograme și ajustări de aspect, păstrând funcționalitățile documentate.
